# GoofBall Cobblemon

A Fabric modpack built around **Cobblemon** (Pokémon in Minecraft) for the GoofBall server: Mega Evolutions,
1500+ Radical Red trainers and gyms, breeding, raids, an economy with a Team Rocket casino, new biomes and
terrain, lots of structures, storage, backpacks, farming, 7 shader packs, and server-side performance mods.

| | |
|---|---|
| Minecraft | **1.21.1** |
| Mod loader | **Fabric** 0.19.5 |
| Cobblemon | **1.8.1** (latest) |
| Java (server) | **21** |
| RAM | players 6–8 GB, server 8–10 GB |

## Download
Every [Release](https://github.com/JustAGoofBall/Minecraft-cobblemon-GoofBall/releases/latest) has two files:

| File | For | Guide |
|---|---|---|
| `GoofBall-Cobblemon-<version>.mrpack` | **Players**: import in Modrinth App, Prism Launcher or ATLauncher | [docs/PLAYERS.md](docs/PLAYERS.md) |
| `GoofBall-Cobblemon-Server-<version>.zip` | **Server**: import in Crafty Controller | [docs/CRAFTY.md](docs/CRAFTY.md) |

Players and the server must always use the **same version**.

### Left out on purpose
| Mod | Why |
|---|---|
| C2ME | Every recent build for 1.21.1 needs Java 22+; the server runs Java 21 |
| Cobblemon: Legends Untold | Its legendary spawns don't work on Cobblemon 1.8 (its advancements point to a removed Cobblemon advancement) |
| Cobblemon × Farmer's Delight Compat | Only supports Cobblemon versions before 1.8 |
| Create | No Fabric build for 1.21.1 |

## How this repo works
```
pack/                     The modpack (packwiz): one small .pw.toml per mod/shader/resource pack
server/                   Extra files for the server zip (server.properties, start scripts)
server-launcher/          goofball-server.jar source: syncs mods from Modrinth, then starts Fabric
scripts/build_server.py   Builds the server zip from the .mrpack
.github/workflows/        Builds the .mrpack and server zip on every push and release
docs/                     Guides
```

There are no jar files in the repo or in the release downloads. Players' launchers and the server
launcher download every mod from Modrinth and check its hash. Each mod keeps its own license; see
its Modrinth page.
