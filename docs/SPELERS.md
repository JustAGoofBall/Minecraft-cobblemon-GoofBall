# Modpack installeren (voor spelers)

Je hebt één bestand nodig: **`GoofBall-Cobblemon-<versie>.mrpack`**.
Download het bij de nieuwste [Release](https://github.com/JustAGoofBall/Minecraft-cobblemon-GoofBall/releases/latest) (onder *Assets*), of installeer het
pack rechtstreeks vanaf Modrinth zodra het daar staat.

> Je hebt een gekochte Minecraft Java Edition-account nodig. Java hoef je niet zelf te installeren:
> de launchers hieronder regelen dat.

## Modrinth App (aanbevolen)
1. Download de Modrinth App via <https://modrinth.com/app> en log in met je Microsoft-account.
2. Klik links op het **+** (*Create instance*) → tab **From file**.
3. Kies het `.mrpack`-bestand → **Import**. De app downloadt alle mods vanzelf.
4. Klik op **Play**.

Staat het pack op Modrinth? Zoek dan in de app naar **GoofBall Cobblemon** en klik op **Install**.

## Prism Launcher
1. Download Prism via <https://prismlauncher.org> en voeg je Microsoft-account toe (rechtsboven).
2. **Add Instance** → links **Import** → kies het `.mrpack`-bestand → **OK**.
3. Selecteer de instance → **Launch**.

## ATLauncher
1. Download ATLauncher via <https://atlauncher.com>.
2. **Instances** → **Import** → kies het `.mrpack`-bestand → **Install**.
3. Start de instance via **Play**.

## Verbinden met de server
Multiplayer → **Add Server** → vul het adres in dat je van de serverbeheerder krijgt.

## Tips
- **Geheugen (RAM):** geef Minecraft minimaal **4 GB**, liefst **6 GB**.
  - Modrinth App: instance → ⚙️ *Settings* → *Java and memory*.
  - Prism: instance → *Edit* → *Settings* → *Java* → *Maximum memory allocation*.
- **Voice chat:** druk op **V** voor het voice chat-menu. Standaard is het *push-to-talk* met **Caps Lock**.
- **Kaart:** **Y** opent het minimap-menu, **M** opent de wereldkaart.
- **Recepten:** EMI staat rechts in je inventaris. Klik op een item voor het recept.
- **Shaders (optioneel):** wil je shaders, voeg dan zelf *Iris Shaders* toe aan je instance.
  De server merkt daar niets van.

## Updaten
- **Modrinth App** (pack geïnstalleerd vanaf Modrinth): je krijgt vanzelf een melding dat er een update is.
- **Geïmporteerd `.mrpack`-bestand:** download de nieuwe `.mrpack` en importeer die opnieuw.
  Wil je je instellingen houden? Kopieer dan `options.txt` en de map `config/` van je oude instance
  naar de nieuwe.

De versie van je modpack moet altijd **dezelfde** zijn als die van de server.
